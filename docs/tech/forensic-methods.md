## 结论摘要

1. **研判的第一步不是选模型，是保证证据链完整。** 自托管全节点 + 带时间戳的多源数据，比任何算法都更决定结论能不能用。【推断】
2. **图上能做四件事，不要混着做**：聚类回答"是不是一伙"，中心性回答"谁是枢纽"，路径回答"钱怎么走"，社区发现回答"还有谁"。选错方法会得出看起来很专业但站不住的结论。【推断】
3. **合成数据集上的高分不能外推。** IBM AMLSim 类数据分布人造，指标再漂亮也不代表实战；换链、换时间窗必须重测分布漂移。【事实】
4. **输出必须是"风险分 + 依据 + 置信度"三元组**，只给分数无法复核，也无法作为证据。【推断】

> 本页讨论"用什么方法还原事实"，落地形态、评分权重与原型排期在[检测模型与原型](./detection-model)。

## 一、数据层

- **自托管全节点**：去除第三方依赖，保证证据链完整性（参考 MDPI 跨层取证框架，DOI 10.3390/electronics15173849）。
- **多源融合**：链上数据 + OFAC / 执法通报 + 商业分析标签 + 社区举报 + 本地设备痕迹（桥接服务检测的浏览器 artifact 分析）。
- **时间维度**：所有标签与特征带时间戳，支持时间衰减与历史回溯。

第三点最容易被忽略。没有 `effective_time` 与 `revoked_time`，标签库就无法回答"这笔交易在当时算不算可疑"，事后回溯与申诉都会失去依据。【推断】

## 二、分析层

| 方法 | 用途 | 代表技术 |
| --- | --- | --- |
| 图分析 | 地址聚类、社区发现、中心性识别 | 交易图、地址图、地址-交易-地址多重图（Elliptic++ 四种视图） |
| 启发式规则 | 实体归因、风险评分 | 六启发式加权评分模型（MDPI DID） |
| 机器学习 | 异常检测与分类 | XGBoost、随机森林、LSTM（时序）、GNN/GCN（关系） |
| 跨链追踪 | 桥接路径重建 | CCLT 递归框架、金额/时间/代币匹配、L1-L2 关联 |
| 合约静态分析 | 土狗币风险识别 | 权限函数扫描、代理合约识别、LP 锁定验证、持币集中度 |
| 模拟交易 | 貔貅盘识别 | 微额买入 + 微额卖出测试，测量真实卖出税 |
| 可解释性 | 支撑人工复核 | SHAP 值解释模型判定依据 |

## 三、模型选择参考

- Elliptic 原始论文中，随机森林（RF）因数据集已含聚合特征而表现优于标准 GCN；Skip-GCN 通过保留原始特征显著优于标准 GCN。【事实】来源：Weber et al., KDD 2019, arXiv:1908.02591
- 跨链场景研究表明，融合 LSTM 时序嵌入与图结构特征的模型在跨链洗钱识别上优于单一基线；SHAP 分析显示**时间线索与地址级行为**贡献最大。【事实】来源：*Evaluating Temporal and Heterogeneous Graph Methods for Anti-Money Laundering*, ACM DOI 10.1145/3844275.3844324
- 重要提醒：合成数据集上的"完美分类"结果不可直接外推到真实场景，需在不同链、不同时间窗做分布漂移测试。【事实】

选择建议：如果只有一笔案子、几千条流水，规则 + 图查询就够了，上模型是浪费；如果要跨案件复用、需要排风险队列，才值得投入训练与校准。【推断】

## 四、误报控制

1. 标签置信度分层 + 时间衰减
2. 多特征联合判定，禁止单特征定性
3. 业务白名单（交易所、做市商、矿池、正规支付）
4. 人工复核闭环，复核结果回流训练
5. 输出"风险分 + 判定依据 + 置信度"三元组，而非单一结论

五条中，第 3 条成本最低、收益最高。多数"疑似洗钱"告警在剔除 CEX 热钱包与做市商后会自动消失——这一类误报不是模型不准，是没做业务白名单。【推断】

## 局限与待验证

- 【待验证】本页方法清单来自公开文献归纳，未在本地数据上做横向对比。
- 【推断】"规则优先、模型后置"的建议基于单案规模判断，万级节点以上需重新评估。
- 【事实】文献结论均以原论文口径为准，换数据集后需重测。
