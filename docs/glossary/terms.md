## 一、链上基础

| 术语 | 英文 / 缩写 | 准确中文表述 | 常见误用 |
| --- | --- | --- | --- |
| UTXO | Unspent Transaction Output | 未花费交易输出 | 说成"账户余额" |
| 账户模型 | Account Model | 账户余额模型 | 与 UTXO 混用 |
| 交易哈希 | Tx Hash / TxID | 交易哈希 | 说成"交易编号" |
| 区块高度 | Block Height | 区块高度 | 说成"区块号" |
| 手续费 | Gas / Fee | 手续费（Gas） | — |
| 交易计数 | Nonce | 交易计数 | 说成"序号" |
| 备注标识 | Memo / Tag / Destination Tag | 充值备注标识 | 忽略不看（实际是最重要的身份线索之一） |
| 智能合约 | Smart Contract | 智能合约 | — |

## 四、灰产链条（行话）

这些是涉案人员的内部用语，用于**识别**，写材料时加引号并注明是行话。

| 行话 | 含义 | 在链条中的位置 |
| --- | --- | --- |
| 跑分 | 用他人账户代收代付，按流水抽佣 | L1–L2 收款与拆分 |
| 卡农 | 出租出借银行卡、收款码的人 | L1 收款 |
| 水房 | 专门负责洗钱的团伙 | L3–L4 归集与清洗 |
| 车手 | 负责取现的人 | L5 变现 |
| 承兑商 | 场外买卖虚拟币的商户（OTC 币商） | L4–L5 兑换与变现 |
| 码商 | 提供收款码的中间人 | L1 收款 |
| 四件套 | 身份证、银行卡、手机卡、U 盾 | L1 工具 |
| 料 | 被害人的个人信息或资金 | 上游 |
| 资金盘 | 以后金补前金的庞氏结构 | 独立模式 |
| 土狗币 | 无实际价值、由私人随意发行的代币 | 资金盘载体 |
| 杀猪盘 | 长期培养感情后实施诈骗 | 上游 |

## 五、法律概念

| 术语 | 法条 | 准确表述 | 注意 |
| --- | --- | --- | --- |
| 帮助信息网络犯罪活动罪 | 刑法第 287 条之二 | 帮信罪 | 需"明知"+情节严重 |
| 掩饰、隐瞒犯罪所得、犯罪所得收益罪 | 刑法第 312 条 | 掩隐罪 | 与洗钱罪区分看上游罪名 |
| 洗钱罪 | 刑法第 191 条 | 洗钱罪 | 上游限七类特定犯罪 |
| 非法经营罪 | 刑法第 225 条 | 非法经营罪 | 用于 OTC 兑换存在争议 |
| 组织、领导传销活动罪 | 刑法第 224 条之一 | 传销罪 | 资金盘常用 |
| 非法金融活动 | 2021 年十部委通知 | 非法金融活动 | 表述固定，不要改写 |
