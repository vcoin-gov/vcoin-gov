# 工具选型一页纸

> 核查基准日 **2026-11-13**；标【待验证】【公开资料未披露】的不得进对外材料。

## 一、选定组合（第一阶段就用这四个，不再逐个挑工具）

| # | 组合 | 用途 | 成本 |
| --- | --- | --- | --- |
| 1 | Etherscan + Tronscan | 查交易、读合约、核哈希（复核基线） | 0 |
| 2 | MetaSleuth + OKLink | 拉资金链、出图、中文地址交叉印证 | 0（额度未公开） |
| 3 | Arkham 网页版 + 原始浏览器 | 判地址归属，双来源印证 | 0（API 收费，不用） |
| 4 | BSC 走 0 成本：网页核对 + 公开通报地址抽样 | 补唯一没有免费 API 的主战场 | 0 |

→ 详见[结论先行](/onchain/tools#结论先行)、[分组推荐](/onchain/tools#五、分组推荐-按场景-不按工具)

## 二、五条核心判断

1. **免费窗口在收缩，且塌陷位置正是主战场。** Etherscan 免费档 3 次/秒、10 万次/日，但 BNB Chain、Base、OP、Avalanche 已转付费；BscScan 免费 API 已取消；Tronscan 必须带 Key；Dune 免费账号已降为只读。→ [评估维度与总表](/onchain/tools#三、工具对比总表-2026-11-13-核查)
2. **「零成本跑完全流程」不成立。** 本期定案：不采购、不自建、不注册，BSC 只做网页核对 + 抽样，接受「个案级、非分布级」的代价。→ [场景 F：BSC 取数怎么办](/onchain/tools#五、分组推荐-按场景-不按工具)
3. **GraphSense 本期不建设。** 有 Tron adapter、没有 BSC adapter，自建补不上主战场；叠加无节点运维人力，只留作预案。→ [自建覆盖结论](/onchain/tools-appendix#二、graphsense-覆盖判断与不建设理由)
4. **商业平台与免费工具的差距在标签可信度与跨链聚类**，不在能不能查到交易；免费路线只能靠多来源交叉印证缓解。→ [逐工具判断](/onchain/tools#四、逐工具判断)
5. **任何关键判断至少两个独立来源。** 单一来源的标签不构成结论；五工具标签横评的判读规则已写死。→ [标签对比判读规则](/onchain/tools-appendix#四、五工具标签横评-样本已定-结果待填)

## 三、成本对照（便于说明"为什么不是全免费"）

| 项目 | 0 成本 | 需付费 |
| --- | --- | --- |
| EVM 主链单案核对 | ✅ Etherscan 网页 + API | —— |
| TRON 单案核对 | ✅ Tronscan 网页（带 Key 限流） | 批量自动化需付费或自建 |
| BSC 单案核对 | ✅ 网页手工 | 批量 API：$49/月起 |
| 资金流图 | ✅ MetaSleuth 免费档（额度未公开） | 大图 / 多节点 |
| 批量统计 | ❌ | Dune $65–75/月起，或 Bitquery |
| 实体标签 API | ❌ | Arkham $100/月起 |
| 数据自主可控 | 人工核对（不做） | 全量：GraphSense + 节点 + 标签积累 |

## 四、已定案的三条边界（2026-11-13）

1. **不采购**付费 API（含 BscScan $49/月、Dune、Arkham API）。
2. **不自建**节点与 GraphSense，仅作能力参照。
3. **不注册账号**做实测；公开资料没写的，标【公开资料未披露】，不估算。

**重启条件**：单专题需 >500 次 BSC 请求，或需连续 7 天监控同一簇地址。
