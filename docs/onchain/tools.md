## 本页要回答的问题

1. 现有工具各自**真正擅长**什么？不是功能列表，是在什么场景下非它不可。
2. **免费额度**够不够日常研判用？超了怎么办？
3. 哪些工具**可以自建**？自建的成本和收益比是多少？
4. 商业工具（Chainalysis / Elliptic 类）与免费工具的**能力差距具体在哪**？
5. 最终推荐**哪几个组合**，而不是列一堆让人挑花眼。

::: warning 本页的写法要求
不要写成工具清单。每个工具必须回答：**解决什么问题 / 别人替代不了的点是什么 / 什么情况下不该用它**。列功能而不给判断的，等于没调研。
:::

## 一、评估维度

统一按这六项打分，避免各说各话。

| 维度 | 说明 | 权重 |
| --- | --- | --- |
| 链覆盖 | 是否覆盖 TRON / BSC（涉诈资金主战场） | 高 |
| 标签质量 | 标签来源是否透明、是否可追溯 | 高 |
| 免费额度 | 个人/小组能否长期白嫖 | 高 |
| 可自建 | 数据是否可自主掌控（关键结论的可信度依赖于此） | 中 |
| 图谱能力 | 是否支持多跳展开、聚类、路径查找 | 中 |
| 中文支持 | 团队使用成本 | 低 |

::: tip 为什么"可自建"权重不低
用第三方工具的标签下结论，等于把结论的可靠性外包给了一个不透明的来源。重要案件的关键判断，最终要靠**自己能复现的数据**。这也是下面要单独讲 GraphSense 的原因。
:::

## 二、工具对比总表

| 工具 | 类型 | 覆盖链 | 免费额度 | 标签 | 图谱 | 可自建 | 最适场景 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **Etherscan** | 浏览器 + API | ETH 及 EVM 系 | API 免费档，有速率限制 | 有，来源不透明 | 无 | 否 | 查单笔交易、读合约、看代币持仓 |
| **Tronscan** | 浏览器 + API | TRON | 免费，有限流 | 基础 | 无 | 否 | **USDT-TRC20 必用** |
| **Blockchair** | 多链浏览器 + API | 20+ 条链 | 免费档（较严） | 有，可筛 | 无 | 否 | 跨链横向对比、批量查地址 |
| **BscScan 等 Etherscan 系** | 浏览器 | BSC / Arbitrum / Polygon 等 | 同 Etherscan | 有 | 无 | 否 | EVM 生态通用查询 |
| **MetaSleuth**（BlockSec） | 可视化追踪 | 多链 | 有免费额度 | 有 | **强** | 否 | 快速拉资金流、出图汇报 |
| **OKLink 链上天眼** | 浏览器 + 追踪 | 多链 | 免费 | 有，中文 | 中 | 否 | 中文场景、国内案件地址查询 |
| **Arkham** | 实体标注 + 追踪 | 多链 | 免费注册 | **实体级标注强** | 中 | 否 | 判断地址属于哪个实体 |
| **Dune Analytics** | SQL 数据平台 | 多链 | 免费版查询受限 | 无 | 无 | 否（数据可导出） | 批量统计、自定义指标 |
| **Bitquery** | GraphQL API | 多链 | 有免费额度 | 弱 | 无 | 否 | 程序化批量拉取 |
| **GraphSense** | 开源分析平台 | BTC / BCH / LTC / ZEC / ETH 等 | 完全免费 | 需自建标签 | 中 | **是** | 自主可控的深度分析 |
| **Blockscout** | 开源浏览器 | EVM 系 | 免费 | 无 | 无 | **是** | 自建私有浏览器，数据不出内网 |
| **Chainalysis / Elliptic** | 商业取证平台 | 多链 | 无（付费，不对个人） | **执法级** | 强 | 否 | 仅作能力参照，不作为方案 |

::: danger 表里所有免费额度都会变
不要照抄数字，**以官网当期政策为准，实测一遍再写进方案**。本表的额度列只表示"有免费档"这个事实。
:::

## 三、分组推荐（按场景，不按工具）

### 场景 A：查一笔具体交易

**Etherscan（ETH 系）+ Tronscan（TRON）**，够用，不用装别的。

关键是会用：看 internal tx（合约内部转账）、看 token transfer（代币流水）、看 input data（合约调用参数）。很多人只看主交易，漏掉内部转账——而涉诈资金大量走合约内部调用。

### 场景 B：快速拉一条资金链

**MetaSleuth** 优先。免费额度做中小规模追踪够用，出图直接能进汇报。

局限：节点一多就要付费；底层标签仍是第三方数据，关键结论要回到原始浏览器复核。

### 场景 C：批量数据、做统计

**Dune**（写 SQL）或 **Bitquery**（写 GraphQL）。

适合"某类地址在过去 30 天内的行为分布"这种问题。不适合单案追踪。

### 场景 D：自主可控的深度分析

**GraphSense 自建**。这是唯一能让你把数据握在自己手里的路线。

代价：需要自己跑区块链节点或导入公开数据，存储和算力成本不低，标签体系要自己积累。**建议作为中长期基础设施，不作为第一阶段的交付**。

### 场景 E：判断地址归属哪个实体

**Arkham** 免费档 + **OKLink** 互相印证。两个来源都指向同一实体，可信度显著提升。

## 四、明确不推荐的方向

| 不推荐 | 原因 |
| --- | --- |
| 同时装五六个浏览器 | 功能高度重叠，切换成本大于收益。EVM 系一个 Etherscan 全够 |
| 一上来就自建全套 | 节点同步、存储、标签积累都是硬成本。先用现成工具跑出需求，再决定自建什么 |
| 依赖单一来源的标签下结论 | 标签错了结论就废了。任何关键判断至少两个独立来源 |
| 追求商业平台的"AI 风险评分" | 黑盒评分无法在报告里解释依据，也过不了质证 |
