  <div class="step-list">

    <div class="step-item"><strong>自动上线</strong>合并触发构建，约 1 分钟后全网可见，页面底部自动显示最后更新时间。</div>

<div class="home-section">
  <h2>本站收录什么</h2>
  <p>不是新闻聚合，而是可复用的研判知识：每条结论都要能回答「依据是什么、怎么验证、什么场景下不成立」。</p>

| 研究方向 | 核心产出 | 落位页面 |
| --- | --- | --- |
| 法规定性 | 法条 / 司法解释 / 案例的适用边界 | [国内法规与司法解释](./policy/domestic-regulation) |
| 跨境差异 | 稳定币、MiCA、美国框架的监管对比 | [境外监管与跨境差异](./policy/overseas-regulation) |
| 案例模式 | 公开通报中的作案手法结构化拆解 | [公开通报案例库](./policy/cases) |
| 链上基础 | UTXO / 账户模型 / 混币 / 跨链 / OTC | [基础链上知识](./onchain/basics) |
| 地址特征 | 大额快转、小额拆分、多地址集散的识别规则 | [异常地址特征](./onchain/address-features) |
| 资金可视化 | 资金流转图、资金树、团伙分层模型 | [链路可视化研究](./onchain/visualization) |
| 工具能力 | Etherscan / Blockchair / 开源溯源项目对比 | [链上分析工具对比](./onchain/tools) |
| 技术原型 | 检测模型、评分思路、可落地工具 | [检测模型与原型](./tech/detection-model) |

</div>
