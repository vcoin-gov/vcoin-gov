## 结论摘要

1. **宣传的核心不是讲犯罪有多严重，而是拆掉平台的"技术光环"。** 受害者信的是"链上透明、去中心化、不受监管"这套话术，破这套话术比讲道理有效。【推断】
2. **土狗币可以做成 3 分钟自检**：读合约权限、看 LP 锁定、查持币集中度、试卖一次。四项都过不代表安全，但任一项不过基本可以放弃。【推断】
3. **反诈提示里最有用的一条是"不出租不出借账户"**，因为这是唯一在事前就能切断的环节，且学生群体正是被重点招募对象。【事实】

## 一、面向公众的"话术—真相"对照

| 常见话术 | 真相 |
| --- | --- |
| "链上公开透明、去中心化公平开奖" | 多数平台仅借链上数据做开奖幌子，赌资存于普通钱包，平台掌握私钥可随时卷走 |
| "匿名参与，不留痕迹" | 所有转账均留在区块链上，可溯源，是公安机关重要证据 |
| "高赔率、稳赚、低门槛小额投注" | 平台内置抽水，长期必亏；"先赢后输"是诱饵，大额投入后限制提现或跑路 |
| "链上下注，无需实名，不受监管" | 本质仍是网络赌博，涉嫌开设赌场罪、赌博罪、组织参与国（境）外赌博罪 |
| "套利机器人 / 量化托管，日赚 1%" | 资金来自后来者本金即庞氏；真能稳定套利无需向公众募资 |

定性依据见[国内法规与司法解释](./domestic-regulation)；行话释义见[涉诈行话速查](../glossary/slang)。

## 二、土狗币参与前自检清单（3 分钟版）

1. 在区块浏览器验证合约是否开源；扫描 `mint` / `blacklist` / `setTax` / `pause` 等权限函数。
2. 确认 LP 是否锁定、锁定比例与期限（短锁或部分锁是典型撤池前兆）。
3. 检查持币集中度：前 5/10 名地址（排除 LP）占比过高即高度控盘。
4. 做微额买入 + 微额卖出模拟测试，确认能否卖出、真实税率多少。
5. 查 Mint / Freeze Authority 是否撤销（Solana）；确认是否代理合约（EVM）。

::: warning 清单的边界
清单能排除"硬 rug"（瞬时撤池、增发攻击），但不能排除"慢 rug"（内部人持续出货），更不能验证社交热度真伪。【推断】

数据侧的事实是：多数 rug pull 发生在代币上线后第一小时内，中位存活时间 < 36 分钟。也就是说，**等你想起来查的时候，往往已经结束了**。【事实】
:::

各检查项对应的风险类型见[重点场景链路画像](../onchain/scenarios)。

## 三、反诈提示

- **不出租、出借、出售**银行卡、支付账户、交易所账户——可能构成帮信罪，情节严重可升格为掩隐罪或上游共犯。
- **不参与"跑分兼职"**——以 USDT 结算的兼职是典型洗钱通道，学生群体是被重点招募对象。
- **警惕"零转账钓鱼"与"同尾号钓鱼"**——复制上一笔交易收款地址的习惯极易导致资金错转。
- **遭遇冻卡先核查资金来源**——若曾向不明地址收款或参与 OTC，应主动配合调查。

## 四、宣传渠道与形式

反洗钱宣传月、社区宣讲、平台弹窗与风险提示、短视频科普、案例通报（如 Ronin 案、Bybit 案、杀猪盘引渡案）、行业承诺书等。

形式选择上的一个判断：**案例通报的效果取决于"损失数字是否可感"**，而科普短视频的效果取决于"是否给出一个能立刻照做的动作"。两者不宜混在同一个物料里。【推断】

## 局限与待验证

- 【推断】"话术—真相"对照表基于公开案例归纳，未做受众测试，实际传播效果未知。
- 【待验证】自检清单的召回率与误杀率均未统计。
- 【事实】法条适用以现行《刑法》及相关司法解释为准，本页不做定性结论。
