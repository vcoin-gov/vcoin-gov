## 本页要回答的问题

1. 现有治理手段在**哪个具体环节**失效？是法律没覆盖、技术打不穿，还是协作走不通？
2. 八类痛点里，哪些是**本质无解**（只能管理不能消灭），哪些是**当前技术可攻**？
3. 每个痛点的**成本结构**是什么？攻破一个要投入多少，对方维持一个要投入多少？
4. 哪些痛点是**被高估的**？（舆论常提但实际影响有限）哪些是**被低估的**？
5. 如果只能选三个方向攻关，选哪三个？依据是什么？

::: tip 本页的写法
不要写成"问题罗列"。每个痛点必须回答四件事：**机理是什么 / 现有手段为什么失效 / 谁在承担成本 / 有没有可攻的缝**。缺一项就是没写完。
:::

## 一、痛点全景

先把八个痛点按**性质**分类，不按话题分类。因为同类痛点的解法相通，跨类的解法互不通用。

| 类别 | 痛点 | 失效层级 | 本质 |
| --- | --- | --- | --- |
| **A. 技术性匿名** | 混币器 / Tornado 类工具 | 技术 | 链上关联被人为切断 |
| | 跨链跳转 | 技术 | 地址体系切换，追踪链路断开 |
| | 假名地址 | 技术 | 地址与真实身份无天然绑定 |
| **B. 通道性脱管** | OTC 场外交易 | 监管 | 交割在链下，无中介留痕 |
| | 匿名（非托管）钱包 | 监管 | 无 KYC 主体可追责 |
| | 本地土狗盘 | 监管 + 资源 | 单案小、分散、跨区域 |
| **C. 机制性障碍** | 跨境资金穿透 | 协作 | 管辖边界 vs 资金无界 |
| | 变现环节滞后 | 协作 + 时效 | 发现时资金已落地境外 |

## 二、逐条展开

### A1 · 混币器与 Tornado 类工具

**机理**：把多人的存款汇入同一资金池，提款时用零知识证明证明"我存过"，但不暴露是哪一笔。存款地址与提款地址在链上**没有任何直接关联**，传统的"顺着转账记录往下爬"完全失效。

**现有手段与失效原因**：

| 手段 | 思路 | 为什么不够 |
| --- | --- | --- |
| 地址黑名单 | 直接标记混币合约与关联地址 | 只封入口不封能力；用户可换前端、换链、换工具 |
| 金额指纹匹配 | 按存款/提款的金额与时间窗口配对 | 池子大了以后同一金额有多笔，配对不唯一 |
| 时序分析 | 存款后短时间内提款视为关联 | 可人为拉长间隔对冲 |
| 制裁与合规施压 | 迫使交易所拒绝混币资金入金 | 依赖交易所配合，去中心化交易所无效 |

**可攻的缝**：

- **出池之后**才是真正的战场。混币切断的是池内关联，切不断出池地址的后续行为特征（归集模式、与 CEX 入金地址的交互、兑现节奏）。
- **CEX 入金地址是硬约束**。最终要变成法币，就必然经过有 KYC 的入口。这条链路是当前唯一稳定的破口。
- **桥接与混币的组合使用会留下时间戳序列**，可作为弱关联证据，但不足以单独定案。

::: warning 一个容易写错的判断
"混币器让资金完全无法追踪"是错的。准确表述是：**混币器切断了池内直接关联，使单笔资金的链上连续性中断，但无法消除出池后的行为特征与法币出口的必然性。** 写材料时这个区别很重要，前者会导致放弃追踪，后者指向正确的攻关方向。
:::

### A2 · 跨链跳转

**机理**：资产从 A 链转到 B 链，中间经过桥的锁定/铸造合约，目标链上生成的是**新的资产凭证**，与原地址无直接转账关系。多跳几次后，原始来源在链上表现为"消失"。

**为什么难**：每条链的浏览器、数据模型、地址格式都不同；桥的中间状态（锁定地址、验证者、流动性池）披露程度不一；部分桥不公开映射关系。

**可攻的缝**：桥的锁定地址是公开的，**入池与出池在时间与金额上存在可统计的对应关系**。对于流动性池模式的桥，跨链前后存在量级上的守恒关系，可作为概率关联。多链数据统一索引是工程问题，不是原理障碍。

### A3 · 假名地址

**机理**：地址本身是假名的，天然不与身份绑定。但**每一次与 KYC 主体的交互都是一次身份泄漏点**。

**可攻的缝**：地址聚类（共同输入、找零地址、交易所充值地址复用）、与已知标签地址的交互图谱、链下信息交叉（社交平台公布的收款地址、勒索信中的地址）。

**边界**：聚类结果是**概率性归集**，不是身份认定。写材料时必须区分"归集为一簇"和"属于某人"，否则在法庭上站不住。

### B1 · OTC 场外交易

**机理**：买卖双方直接转账，平台只做撮合与担保。人民币交割走银行卡/支付宝，虚拟币交割走链上，两段链路天然分离。

**为什么难**：

- 没有统一的中央对手方留痕，单笔金额可大可小
- 担保人（承兑商）模式引入额外一层，责任分散
- 大量交易在即时通讯工具里完成，证据易灭失

**成本视角**：对币商而言，被查的主要风险是银行卡被止付和账户被冻结，而单笔利润足以覆盖。**当违规成本低于单次收益，事后打击无法形成抑制**——这是经济学问题，不是技术问题。

**可攻的缝**：币商的链上地址是稳定的（长期复用少数地址做归集），行为模式高度重复。**识别一个币商比识别一笔交易容易得多。**

### B2 · 匿名（非托管）钱包

**机理**：私钥自持，无中介，无 KYC。

**真正的争议点**：这类钱包本身是中性工具，把它当治理对象在法理上站不住。**治理对象应是"资金流经的行为"，不是"工具本身"。** 写对策建议时如果把"禁用非托管钱包"当结论，会被直接否掉。

**可攻的缝**：不做工具管控，做**出口管控**——变现、消费、兑入合规体系时的节点是唯一有效抓手。

### B3 · 本地土狗盘

**机理**：地方性小盘子，币自己发，盘自己控，参与者多为本地熟人网络，金额从几千到几万。

**为什么难**：

- 单案金额小，达不到立案标准或优先级低
- 参与人往往既是受害人又是推广人，取证配合度低
- 服务器、发币合约可能在境外，但推广完全在本地社群
- 类目混杂：有的构成传销，有的只是投机亏损，法律定性成本高

**可攻的缝**：**这类盘子的推广环节是本地化的、可触达的**。与前面几类"技术无解"不同，土狗盘的问题在资源投入和定性标准，不在技术。

### C1 · 跨境资金穿透

**机理**：资金出境无国界，管辖有边界。司法协助请求的周期以月计，资金流转以分钟计。

**成本对比**：

| 环节 | 攻击方成本 | 防守方成本 |
| --- | --- | --- |
| 资金转移 | 分钟级、手续费低 | 调证周期数周至数月 |
| 身份隐藏 | 买一套壳成本数千元 | 穿透一层壳需跨国协作 |
| 平台搭建 | 境外服务器 + 现成模板 | 需两国同时行动才能关停 |

**结论**：这不是"努力就能追上"的差距，是**结构性不对称**。对策不应是"追得更快"，而应是"让资金在出境前被拦住"——把战场前移到境内收款环节。

### C2 · 变现环节滞后

**机理**：案件发现往往在被害人报案之后，此时资金已完成多级流转。

**可攻的缝**：**时效前置**。止付冻结的价值随时间指数衰减，第一小时的处置效果远高于第一周。技术侧能贡献的是**自动化预警**（账户异常行为实时识别），而不是事后溯源。

## 三、痛点矩阵（排优先级用）

横轴是可解性，纵轴是影响面。**右上角是应该优先攻关的**。

| | 影响面大 | 影响面小 |
| --- | --- | --- |
| **技术可攻** | 跨链跳转追踪、假名地址聚类、CEX 出口锁定 | 单链内资金归集分析 |
| **技术难攻** | 混币器池内关联、跨境即时冻结 | 桥的中间状态透明化 |
| **本质无解（只能管理）** | 跨境管辖冲突、非托管钱包匿名性 | 土狗币定价难题 |

## 四、被高估与被低估的痛点

这一节专门用来纠偏，写材料时能避免跟着舆论跑。

| 判断 | 痛点 | 理由 |
| --- | --- | --- |
| 被高估 | 混币器 | 舆论视为"终极隐身"，实际只切断池内关联，出口仍在 CEX。真正难的是跨境协作，不是混币本身 |
| 被高估 | 匿名钱包 | 工具中性，管控无抓手也无必要；真正的风险在变现环节 |
| 被低估 | OTC 币商 | 所有资金最终要落地法币，币商是必经节点，且识别成本远低于追单笔资金 |
| 被低估 | 本地土狗盘 | 单案小但总量大、涉及面广、易引发群体性事件，治理价值被立案标准掩盖 |
| 被低估 | 收款侧预防 | 所有事后溯源加起来，不如把第一笔钱拦在境内 |
