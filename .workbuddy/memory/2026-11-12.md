### 踩过的坑
- VitePress `preview` 服务在 `build` 期间会读到不一致的 dist（CSS 404、只渲染 logo），**build 后必须重启 preview**
- `gh api /repos/...` 在 Git Bash 下要省略前导斜杠，否则被当路径转换
- 仓库 PATCH 接口不接受 topics，要用 `PUT repos/{owner}/{repo}/topics`
- Pages 必须在 push **之前**启用，否则 workflow 报 `Get Pages site failed`
- 首页不要同时用 `features` 和自定义分组卡片，内容重复
